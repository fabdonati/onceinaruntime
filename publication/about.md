# About Once in a Runtime

I like exploring ideas in software, especially when there’s something interesting hiding in the small print.

*Once in a Runtime* is where I explore programming, systems and new technology, from language features and software design to performance and trading systems, with room for the occasional unexpected detour.

I’m Fabrizio Donati, a software engineer working with numerical software. Articles are free, and the code lives on [GitHub](https://github.com/fabdonati/onceinaruntime).
