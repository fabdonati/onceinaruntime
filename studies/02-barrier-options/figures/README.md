# Article figures

These four figures follow the [article](../article.md) from the payoff rule
through the measured pricing costs.

| Position | File | Distinct purpose |
| --- | --- | --- |
| 1 | [01-stock-paths.png](01-stock-paths.png) | Small illustration of paths stopping at a barrier. |
| 2 | [02-simd-mechanism.png](02-simd-mechanism.png) | Invented two-lane example; logical rounds, not measured time. |
| 3 | [03-lanes-and-time.png](03-lanes-and-time.png) | Six-case comparison: occupancy context and every fixed/refill timing. |
| 4 | [04-whole-valuation.png](04-whole-valuation.png) | Phase shares from the same complete-valuation intervals. |

SVG versions are included. The three `03-barrier-*` images show the timing
comparison one barrier at a time. The `05-run-diagnostic` figure shows timing
and host load in run order.

`mechanism-example.json` describes the two-lane example. To regenerate the
figures from a saved campaign, follow the [run guide](../environment.md).
